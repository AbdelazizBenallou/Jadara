================================================================
  GET PROJECT API — GET /v1/projects/:id
  Base URL: http://localhost:3001
  Auth: project owner only (verifyAccessToken)
  Rate limit: 60 requests per minute
================================================================

Returns one of the logged-in user's projects with:
  - full reviews array (who rated, rating, feedback, dates)
  - rating summary { average, count }
  - evidence with download_url (presigned MinIO link, 1h)

Ownership is enforced: only user_id owner can view.

2. PROJECT NOT FOUND (404)
--------------------------------------------------
curl -s -b /tmp/jadara/ben_cookies.txt "http://localhost:3001/v1/projects/999"

--------------------------------------------------
3. NOT OWNER (403)
--------------------------------------------------

--------------------------------------------------
4. INVALID ID (400) / NO AUTH (401)
--------------------------------------------------

NOTES
- This is the answer to "get the review of the project by user":
  each review includes reviewer id/email/profile, rating 1-10,
  feedback, created_at/updated_at.
- Admin has a separate admin view: GET /v1/projects/:id/admin
  (see doc/projects/admin-projects.txt).
