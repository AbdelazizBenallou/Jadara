================================================================
  PUBLIC PROFILE API — GET /v1/users/:id/profile
  Base URL: http://localhost:3001
  Auth: any authenticated user (beneficiary, reviewer, company, admin)
================================================================


--------------------------------------------------
1. NO ACCESS TOKEN (401)
--------------------------------------------------
curl -X GET http://localhost:3001/v1/users/10/profile

Expected: 401
Response: { "success": false, "message": "Unauthorized" }


--------------------------------------------------
2. VIEW ANOTHER USER (200)
--------------------------------------------------
curl -X GET http://localhost:3001/v1/users/10/profile \
  -b ben-cookies.txt

Expected: 200

curl -X GET http://localhost:3001/v1/users/1/profile \
  -b company-cookies.txt     # any authenticated user can view anyone


--------------------------------------------------
3. USER NOT FOUND (404)
--------------------------------------------------
curl -X GET http://localhost:3001/v1/users/999/profile \
  -b ben-cookies.txt

Expected: 404
Response: { "success": false, "message": "User not found" }


--------------------------------------------------
4. INVALID USER ID (NaN) (400)
--------------------------------------------------
curl -X GET http://localhost:3001/v1/users/abc/profile \
  -b ben-cookies.txt

Expected: 400
Response: { "success": false, "message": "Invalid user ID" }


--------------------------------------------------
5. RATE LIMIT (429)
--------------------------------------------------
for i in {1..31}; do
  curl -s -o /dev/null -w "%{http_code}\n" \
    -X GET http://localhost:3001/v1/users/10/profile \
    -b ben-cookies.txt
done

Expected: first 30 return 200, 31st returns 429


--------------------------------------------------
