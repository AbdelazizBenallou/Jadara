================================================================
  DOMAIN ↔ SKILLS APIs
    GET  /v1/domains/:id/skills   — list skills of a domain
    POST /v1/domains/:id/skills   — admin links a skill
  Base URL: http://localhost:3001
  Permissions:
    GET  -> view_domains   (Admin + all baseline roles)
    POST -> update_domain  (Admin only)
================================================================

Setup:

curl -s -X POST http://localhost:3001/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{ "email": "admin@jadara.com", "password": "Admin@12345" }' \
  -c /tmp/admin-cookies.txt

==================================================
POST /v1/domains/:id/skills
=================================================
Body: EITHER single skill OR many skills:
  { "skill_id": <number> }
  { "skill_ids": [<number>, ...] }   (1–50 ids, duplicates removed)

Business logic (PARTIAL MODE — accepts what exists, reports the rest):
  1. validate shape            -> 422 if neither / both fields
  2. domain must exist         -> 404
  3. duplicates in input       -> auto-deduped
  4. each id lands in ONE bucket:
       added          = exists & newly linked      -> inserted (createMany)
       already_linked = exists & already attached  -> skipped, no error
       not_found      = does NOT exist             -> refused & REPORTED back
  5. always 200 on success (even if all ids were fake: added: [])
     only errors left: 404 bad domain / 403 no permission / 422 bad shape
  6. response includes full refreshed skill list

--------------------------------------------------
6. VALIDATION ERRORS (422)
--------------------------------------------------

--- Empty body ---
-d '{}'
Expected: 422 {"success":false,"message":"Validation failed",
               "errors":{"skill_id":["Either skill_id or skill_ids is required"]}}

--- Both fields at once ---
-d '{ "skill_id": 20, "skill_ids": [21] }'
Expected: 422 {"success":false,"message":"Validation failed",
               "errors":{"skill_id":["Provide either skill_id or skill_ids, not both"]}}

--- Empty array ---
-d '{ "skill_ids": [] }'
Expected: 422 errors.skill_ids ["Too small: expected array to have >=1 items"]

--- Bad values ---
-d '{ "skill_id": -1 }'              Expected: 422
-d '{ "skill_ids": [0, "x", null] }' Expected: 422
